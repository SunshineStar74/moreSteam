Put the steam sounds here, as mono .ogg (Ogg Vorbis) files:

  idle_burst.ogg  - one cylinder of a standing train letting off a burst (the burst lasts 5 s by default)
  stop_burst.ogg  - the cylinders blowing off steam as the train stops (about 1.5 s for now)

Mono matters: Minecraft only plays sounds from a position in the world if the file is mono.
To add variations, put more files here (e.g. idle_burst2.ogg) and list them in assets/moresteam/sounds.json.
